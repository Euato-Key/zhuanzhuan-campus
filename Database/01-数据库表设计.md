# 数据库表设计

根据需求.md分析，本项目需要建立以下数据库表：

---

## 一、用户模块

### 1.1 用户表 (users)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PRIMARY KEY AUTO_INCREMENT | 用户ID |
| email | VARCHAR(255) UNIQUE NOT NULL | 邮箱 |
| username | VARCHAR(50) UNIQUE NOT NULL | 用户名 |
| password | VARCHAR(255) NOT NULL | 密码(加密) |
| avatar | VARCHAR(500) | 头像URL |
| school | VARCHAR(100) | 学校名称 |
| campus | VARCHAR(100) | 校区名称 |
| phone | VARCHAR(20) | 手机号 |
| role | ENUM('user','admin','super_admin') DEFAULT 'user' | 角色 |
| credit_score | INT DEFAULT 100 | 信用分(0-150) |
| credit_level | ENUM('excellent','good','average','poor') DEFAULT 'good' | 信用等级 |
| is_blocked | TINYINT(1) DEFAULT 0 | 是否被封禁 |
| blocked_until | DATETIME | 封禁截止时间 |
| last_login_at | DATETIME | 最后登录时间 |
| login_fail_count | INT DEFAULT 0 | 登录失败次数 |
| created_at | DATETIME DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

---

## 二、商品模块

### 2.1 商品分类表 (categories)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PRIMARY KEY AUTO_INCREMENT | 分类ID |
| name | VARCHAR(50) NOT NULL | 分类名称 |
| parent_id | INT NULL | 父分类ID(顶级为NULL) |
| icon | VARCHAR(500) | 图标URL |
| sort | INT DEFAULT 0 | 排序 |
| created_at | DATETIME DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

### 2.2 商品表 (products)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PRIMARY KEY AUTO_INCREMENT | 商品ID |
| user_id | INT NOT NULL | 卖家ID |
| name | VARCHAR(100) NOT NULL | 商品名称 |
| description | TEXT | 商品描述 |
| category_id | INT NOT NULL | 分类ID |
| tags | JSON | 商品标签数组 |
| images | JSON NOT NULL | 主图URL数组(1-9张) |
| detail_images | JSON | 详情图片数组 |
| original_price | DECIMAL(10,2) | 原价 |
| current_price | DECIMAL(10,2) NOT NULL | 现价 |
| bargain | TINYINT(1) DEFAULT 0 | 是否支持议价(0/1) |
| delivery_type | ENUM('self','express','both') NOT NULL | 交易方式 |
| pickup_address | VARCHAR(255) | 自提地点 |
| pickup_time | VARCHAR(255) | 自提时间段 |
| condition | ENUM('new','99new','95new','90new','80new') NOT NULL | 新旧程度 |
| stock | INT DEFAULT 1 | 库存数量 |
| brand | VARCHAR(100) | 品牌 |
| specs | JSON | 规格自定义JSON |
| shipping_address | VARCHAR(255) | 发货地址 |
| valid_days | INT | 有效期(天,永久为NULL) |
| expire_time | DATETIME | 过期时间 |
| status | ENUM('pending','active','offline','banned','audit_failed') DEFAULT 'pending' | 状态 |
| reject_reason | TEXT | 审核拒绝原因 |
| audit_count | INT DEFAULT 0 | 审核次数 |
| view_count | INT DEFAULT 0 | 浏览次数 |
| favorite_count | INT DEFAULT 0 | 收藏数 |
| created_at | DATETIME DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

### 2.3 商品库存锁表 (product_locks)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PRIMARY KEY AUTO_INCREMENT | 锁ID |
| product_id | INT NOT NULL | 商品ID |
| order_id | INT NOT NULL | 订单ID |
| quantity | INT NOT NULL | 锁定数量 |
| locked_until | DATETIME NOT NULL | 锁过期时间 |
| created_at | DATETIME DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 表关系说明

```
users (1) ──────────< (N) products
users (1) ──────────< (N) orders (buyer_id)
users (1) ──────────< (N) orders (seller_id)
users (1) ──────────< (N) reviews (reviewer_id)
users (1) ──────────< (N) favorites
users (1) ──────────< (N) addresses
users (1) ──────────< (N) notifications
users (1) ──────────< (N) want_buys
users (1) ──────────< (N) want_buy_comments

products (1) ───────< (N) orders
products (1) ───────< (N) reviews
products (1) ───────< (N) favorites

categories (1) ────< (N) products
categories (1) ────< (N) categories (parent_id)

orders (1) ────────< (N) reviews

conversations (1) ─< (N) messages

want_buys (1) ─────< (N) want_buy_comments
```
