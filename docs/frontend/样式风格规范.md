# 转转校园二手平台 - 前端样式风格规范

## 1. 设计概述

### 1.1 设计理念

清新、自然、年轻化，体现校园的生机与活力，传递环保、诚信的交易氛围。

### 1.2 目标用户

在校大学生、研究生，追求性价比，关注商品质量和交易安全。

## 3. 字体系统

### 3.1 字体家族

```scss
// 优先使用系统字体，保证加载速度和兼容性
$font-family-cn: -apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", sans-serif;
$font-family-en: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
```

### 3.2 字号层级

| 级别 | 字号 | 行高 | 用途 |

## 8. 动画规范

### 8.1 过渡时长

| 类型 | 时长 | 场景 |
|-----|------|------|
| 快速 | 150ms | 交互反馈、颜色变化 |
| 常规 | 250ms | 元素移动、尺寸变化 |
| 缓慢 | 400ms | 页面切换、模态框 |

### 8.2 缓动函数

```scss
$ease-out: cubic-bezier(0.215, 0.61, 0.355, 1);  // 弹出、进入
$ease-in: cubic-bezier(0.55, 0.055, 0.675, 0.19); // 退出、离开
$ease-in-out: cubic-bezier(0.645, 0.045, 0.355, 1); // 往复运动
```

## 10. 实现说明

### 10.1 文件结构

```
frontend/src/assets/styles/
├── _variables.scss    # 变量定义（颜色、间距、圆角等）
├── _mixins.scss       # 混合宏
├── _reset.scss        # 重置样式
├── _typography.scss   # 字体排版
├── _components.scss   # 通用组件样式
├── _animations.scss   # 动画定义
└── main.scss          # 入口文件
```

### 10.2 使用方式

```scss
// 在组件中使用
<style scoped lang="scss">
@import '@/assets/styles/variables';

.my-component {
  color: $color-primary;
  border-radius: $radius-md;
}
</style>
```

## 11. 注意事项

1. **优先使用 CSS 变量**：便于主题切换和维护
2. **保持一致性**：相同场景使用相同的间距、颜色
3. **考虑无障碍**：确保对比度符合 WCAG 2.1 标准
4. **性能优先**：避免过多的动画和复杂的 CSS 选择器
5. **Element Plus 配合**：自定义样式时覆盖 Element Plus 组件的默认样式，使用 CSS 变量保持一致性
