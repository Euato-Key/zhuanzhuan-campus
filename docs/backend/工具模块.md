# 工具模块

## 概述

工具模块 (`backend/src/utils/`) 提供了通用工具函数，用于统一响应格式和邮件发送。

## 模块列表

| 文件 | 说明 |
|------|------|
| response.ts | 统一 API 响应格式和特殊类型序列化 |
| email.ts | 邮件发送（QQ 邮箱 SMTP） |

---

## response.ts - 统一响应格式

### 功能

提供统一的 API 响应格式，并自动处理 BigInt、Decimal、Date 等特殊类型的序列化。

### API

```typescript
import { success, fail } from '../utils/response';

// 成功响应
success(res, data, '操作成功', 200);

// 失败响应
fail(res, '参数错误', 400);
```

### 响应格式

```typescript
interface ApiResponse<T = unknown> {
  code: number;      // HTTP 状态码
  data: T | null;    // 响应数据
  message: string;   // 描述信息
}
```

成功响应示例：
```json
{
  "code": 200,
  "data": { "id": "1", "name": "测试商品" },
  "message": "success"
}
```

失败响应示例：
```json
{
  "code": 400,
  "data": null,
  "message": "参数错误"
}
```

### 自动序列化

`response.ts` 会自动处理以下特殊类型：

| 类型 | 序列化结果 |
|------|-----------|
| `BigInt` | 转为字符串 `"123456789"` |
| `Decimal` | 转为数字 `99.99` |
| `Date` | 转为 ISO 字符串 `"2024-01-01T00:00:00.000Z"` |

**为什么需要序列化？**

- `JSON.stringify` 无法处理 BigInt，会抛出 `TypeError: Do not know how to serialize a BigInt`
- Prisma 的 `Decimal` 类型需要显式转换
- Date 对象序列化后的格式可能不符合预期

### 使用示例

```typescript
import { success, fail } from '../../utils/response';
import { asyncHandler } from '../../common/asyncHandler';

export const SomeController = {
  // 成功响应（默认 200）
  getList: asyncHandler(async (req, res) => {
    const data = await Service.getList();
    return success(res, data);  // 自动处理 BigInt/Decimal/Date
  }),

  // 成功响应（自定义消息）
  create: asyncHandler(async (req, res) => {
    const data = await Service.create(req.body);
    return success(res, data, '创建成功', 201);
  }),

  // 失败响应
  getDetail: asyncHandler(async (req, res) => {
    const id = req.params.id;
    if (!id) {
      return fail(res, 'ID 不能为空', 400);
    }
    const data = await Service.getById(id);
    if (!data) {
      return fail(res, '资源不存在', 404);
    }
    return success(res, data);
  }),
};
```

### 与错误处理配合

推荐在 Controller 层使用 `asyncHandler`，让错误自动被捕获并返回失败响应：

```typescript
// ✅ 推荐：使用 asyncHandler + throw AppError
const create = asyncHandler(async (req, res) => {
  const result = await Service.create(req.body);  // Service 中可能 throw badRequest
  return success(res, result);
});

// ❌ 不推荐：手动 try-catch
const create = async (req, res) => {
  try {
    const result = await Service.create(req.body);
    return success(res, result);
  } catch (err: any) {
    return fail(res, err.message, err.statusCode || 500);
  }
};
```

## email.ts - 邮件发送

### 功能

使用 QQ 箱 SMTP 发送验证码邮件，支持多种验证码类型。

### 配置要求

需要在 `.env` 中配置：

```env
QQ_EMAIL="your-qq@qq.com"
SMTP_AUTH_CODE="your-smtp-auth-code"  # 不是 QQ 密码，是邮箱授权码
```

### 获取 SMTP 授权码

1. 登录 QQ 邮箱网页版
2. 进入「设置」→「账户」
3. 开启 POP3/SMTP 服务
4. 生成授权码（16 位字符串）

### API

```typescript
import { sendEmailCode } from '../utils/email';

// 发送验证码邮件
await sendEmailCode('user@example.com', '123456', 'register');
```

### 验证码类型

| type | 邮件标题 |
|------|---------|
| `register` | 转转校园 - 注册验证码 |
| `login` | 转转校园 - 登录验证码 |
| `reset_password` | 转转校园 - 重置密码验证码 |
| `change_email` | 转转校园 - 更换邮箱验证码 |

### 邮件模板

邮件采用 HTML 格式，包含：

- 项目 Logo 和名称
- 验证码类型说明
- 6 位验证码（大字体显示）
- 有效期提示（5 分钟）
- 安全提示

邮件样式：
```html
<div style="max-width:600px;margin:0 auto;padding:20px;font-family:sans-serif;">
  <h2 style="color:#4CAF50;">转转校园</h2>
  <p>您正在进行<strong>注册</strong>操作，验证码为：</p>
  <div style="font-size:32px;font-weight:bold;color:#4CAF50;letter-spacing:6px;margin:20px 0;">123456</div>
  <p style="color:#999;">验证码5分钟内有效，请勿泄露给他人。</p>
  ...
</div>
```

### 使用示例

```typescript
import { sendEmailCode } from '../utils/email';
import { VerificationUtil, EmailCodeType } from '../common/verification';

async function sendCode(email: string, type: EmailCodeType) {
  // 生成验证码
  const code = await VerificationUtil.createCode(email, type);

  // 发送邮件
  await sendEmailCode(email, code, type);
}
```

### SMTP 配置

```typescript
const transporter = nodemailer.createTransport({
  host: 'smtp.qq.com',
  port: 465,
  secure: true,  // SSL
  auth: {
    user: env.QQ_EMAIL,
    pass: env.SMTP_AUTH_CODE,
  },
});
```

### 错误处理

邮件发送失败时会抛出错误，建议在调用处捕获：

```typescript
try {
  await sendEmailCode(email, code, type);
} catch (error) {
  console.error('[Email] 发送失败:', error);
  throw badRequest('邮件发送失败，请稍后重试');
}
```

## 最佳实践

### 响应格式

1. **统一使用 success/fail**：不要直接调用 `res.json()`
2. **让 asyncHandler 处理错误**：避免手动 try-catch
3. **HTTP 状态码与业务状态码一致**：`success(res, data, 'msg', 201)` 返回 `{ code: 201, ... }`

### 邮件发送

1. **频率限制**：同一邮箱 1 分钟内只能发送一次
2. **验证码有效期**：5 分钟
3. **安全提示**：邮件中提醒用户不要泄露验证码
4. **错误处理**：捕获发送失败，给用户友好提示

## 常见问题

### Q: 为什么 BigInt 需要特殊处理？

A: JavaScript 的 `JSON.stringify` 不支持 BigInt 类型，直接调用会抛出错误。Prisma 使用 BigInt 作为自增主键类型。

### Q: Decimal 转为 Number 会丢失精度吗？

A: 对于价格等字段（通常两位小数），Number 类型足够。如果需要更高精度，可以保留 Decimal 类型并手动处理。

### Q: 邮件发送很慢怎么办？

A: SMTP 发送通常需要几秒，建议：
- 异步发送，不阻塞主流程
- 使用队列（如 Bull）批量发送
- 考虑使用专业邮件服务（如阿里云邮件推送）

### Q: 如何自定义邮件模板？

A: 可以修改 `email.ts` 中的 HTML 模板，或创建新的模板函数。建议保持统一的品牌风格。
