# 认证模块（Auth）

## 模块概述

认证模块负责用户注册、登录、Token 管理和邮箱验证码功能。采用双 Token 机制（Access Token + Refresh Token），支持邮箱+密码登录和邮箱+验证码登录两种方式。

## 目录结构

```
src/modules/auth/
├── auth.routes.ts       # 路由定义
├── auth.controller.ts   # 请求处理、参数校验
└── auth.service.ts      # 业务逻辑
```

## API 接口

### 1. 发送邮箱验证码

`POST /api/auth/send-code`

| 参数   | 类型   | 必填 | 说明                                                         |
| ------ | ------ | ---- | ------------------------------------------------------------ |
| email  | string | 是   | 接收验证码的邮箱                                             |
| type   | string | 是   | `register` / `login` / `reset_password` / `change_email`    |

限制：同一邮箱 1 分钟内只能发送一次，验证码 5 分钟有效。

### 2. 用户注册

`POST /api/auth/register`

| 参数     | 类型   | 必填 | 说明            |
| -------- | ------ | ---- | --------------- |
| email    | string | 是   | 邮箱            |
| code     | string | 是   | 6 位邮箱验证码  |
| username | string | 是   | 用户名（2-50位）|
| password | string | 是   | 密码（至少6位） |

### 3. 邮箱+密码登录

`POST /api/auth/login/password`

| 参数     | 类型   | 必填 | 说明 |
| -------- | ------ | ---- | ---- |
| email    | string | 是   | 邮箱 |
| password | string | 是   | 密码 |

连续 5 次密码错误锁定 30 分钟。登录成功返回 Access Token 并通过 `Set-Cookie` 设置 HttpOnly 的 Refresh Token。

### 4. 邮箱+验证码登录

`POST /api/auth/login/code`

| 参数  | 类型   | 必填 | 说明            |
| ----- | ------ | ---- | --------------- |
| email | string | 是   | 邮箱            |
| code  | string | 是   | 6 位邮箱验证码  |

需先调用 `send-code`（type=login）获取验证码。登录成功同样返回双 Token。

### 5. 刷新 Token

`POST /api/auth/refresh-token`

无需请求体，自动从 Cookie 读取 Refresh Token。采用 Token 轮换机制，旧 Refresh Token 自动吊销。

### 6. 退出登录

`POST /api/auth/logout`

需携带 Access Token（Bearer Header）。吊销 Cookie 中的 Refresh Token 并清除 Cookie。

### 7. 重置密码

`POST /api/auth/reset-password`

| 参数         | 类型   | 必填 | 说明            |
| ------------ | ------ | ---- | --------------- |
| email        | string | 是   | 注册邮箱        |
| code         | string | 是   | 6 位验证码      |
| new_password | string | 是   | 新密码（至少6位）|

重置后所有 Refresh Token 自动吊销。

### 8. 获取当前用户信息

`GET /api/auth/profile`

需携带 Access Token。

## 双 Token 机制

| Token 类型   | 有效期 | 存储方式                  | 用途               |
| ------------ | ------ | ------------------------- | ------------------ |
| Access Token | 60 分钟| 前端内存 / Bearer Header  | 接口鉴权           |
| Refresh Token| 30 天  | HttpOnly Cookie           | 刷新 Access Token  |

- Refresh Token 在数据库中存储 SHA-256 哈希值，非明文
- 刷新时采用轮换机制：旧 Token 吊销，签发新 Token
- 退出登录或重置密码时批量吊销该用户所有 Refresh Token

## 响应格式

所有接口统一返回：

```json
{ "code": 200, "data": {}, "message": "success" }
```

错误响应：

```json
{ "code": 400, "data": null, "message": "错误描述" }
```
