# 高校模块（University）

## 模块概述

高校模块提供高校信息查询功能，数据来源于数据库预置数据。支持按省份筛选和关键词搜索。

## 目录结构

```
src/modules/university/
├── university.routes.ts       # 路由定义
├── university.controller.ts   # 请求处理、参数校验
└── university.service.ts      # 业务逻辑
```

## API 接口

所有接口为公开接口，无需登录。

### 1. 搜索高校

`GET /api/universities/search`

按关键词、省份、办学层次搜索高校，支持分页。

| 参数     | 类型   | 必填 | 说明                                          |
| -------- | ------ | ---- | --------------------------------------------- |
| keyword  | string | 否   | 按关键词搜索（模糊匹配）                     |
| province | string | 否   | 按省份筛选                                   |
| level    | string | 否   | 办学层次筛选                                 |
| page     | number | 否   | 页码，默认 1                                 |
| pageSize | number | 否   | 每页数量，默认 10                            |

### 2. 获取省份列表

`GET /api/universities/provinces`

返回所有有高校数据的省份名称列表。

### 3. 按省份获取高校列表

`GET /api/universities/list?province=xxx`

| 参数     | 类型   | 必填 | 说明         |
| -------- | ------ | ---- | ------------ |
| province | string | 是   | 省份名称     |

返回指定省份下的所有高校信息。
