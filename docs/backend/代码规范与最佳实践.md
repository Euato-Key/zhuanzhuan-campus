# 代码规范与最佳实践

## 概述

本文档总结了后端代码的开发规范和最佳实践，帮助保持代码质量和一致性。

---

## 错误处理

### 使用 AppError 类

统一使用 `AppError` 或其快捷方法，避免手动构造错误对象。

```typescript
// ❌ 不推荐
throw Object.assign(new Error('用户不存在'), { statusCode: 404 });

// ✅ 推荐
import { notFound, badRequest, unauthorized, forbidden, conflict } from '../common/errors';

throw notFound('用户不存在');
throw badRequest('参数错误');
throw unauthorized('未登录');
throw forbidden('无权限访问');
throw conflict('用户名已存在');
```

### 在 Controller 中使用 asyncHandler

使用 `asyncHandler` 包装器自动捕获异常，避免重复的 try-catch。

```typescript
// ❌ 不推荐 - 每个 controller 方法都要写 try-catch
export const UserController = {
  async getProfile(req: Request, res: Response) {
    try {
      const user = await UserService.getProfile(req.user!.userId);
      return success(res, user);
    } catch (err: any) {
      return fail(res, err.message, err.statusCode || 500);
    }
  },
};

// ✅ 推荐 - 使用 asyncHandler
import { asyncHandler } from '../common/asyncHandler';

export const UserController = {
  getProfile: asyncHandler(async (req: Request, res: Response) => {
    const user = await UserService.getProfile(req.user!.userId);
    return success(res, user);
  }),
};
```

## 安全规范

### 验证码生成

使用加密安全的随机数生成器。

```typescript
// ❌ 不安全 - Math.random() 可预测
const code = Math.random().toString().slice(2, 8);

// ✅ 安全 - 使用 crypto.randomInt
import { VerificationUtil } from '../common/verification';
const code = VerificationUtil.generateCode();
```

### 验证码比较

使用时序安全的比较方法，防止时序攻击。

```typescript
// ❌ 不安全 - 普通字符串比较可能泄露信息
if (inputCode === storedCode) { ... }

// ✅ 安全 - 使用 VerificationUtil 自动处理
const emailCode = await VerificationUtil.verifyEmailCode(email, code, type);
```

### 密码处理

统一使用 `PasswordUtil` 工具。

```typescript
// ✅ 推荐
import { PasswordUtil } from '../common/password';

const hash = await PasswordUtil.hash(password);
const isValid = await PasswordUtil.verify(password, hash);
```

### 环境变量验证

必需的环境变量在启动时验证。

```typescript
// config/env.ts 已实现启动验证
// 缺少必需变量时会抛出错误：
// Error: 缺少必需的环境变量: JWT_ACCESS_SECRET, JWT_REFRESH_SECRET
```

## 代码复用

### 使用公共工具

优先使用 `common/` 目录下的工具，避免重复代码。

| 场景 | 使用工具 |
|------|----------|
| 抛出错误 | `AppError`, `badRequest`, `notFound` 等 |
| 密码处理 | `PasswordUtil` |
| 验证码 | `VerificationUtil` |
| 分页 | `PaginationUtil` |
| Token 管理 | `TokenUtil` |
| 查询字段 | `selects.ts` 中的常量 |

### 提取重复逻辑

当相同逻辑出现 2 次以上时，考虑提取为公共函数。

```typescript
// ❌ 重复代码
// auth.service.ts
const emailCode = await prisma.emailCode.findFirst({
  where: { email, type: 'register', isUsed: false, expiresAt: { gt: new Date() } },
});
if (!emailCode) throw badRequest('验证码无效或已过期');
if (emailCode.code !== code) throw badRequest('验证码错误');

// user.service.ts - 相同逻辑
const emailCode = await prisma.emailCode.findFirst({
  where: { email, type: 'change_email', isUsed: false, expiresAt: { gt: new Date() } },
});
if (!emailCode) throw badRequest('验证码无效或已过期');
if (emailCode.code !== code) throw badRequest('验证码错误');

// ✅ 提取为工具函数
const emailCode = await VerificationUtil.verifyEmailCode(email, code, type);
```

## 数据库操作

### 使用 Prisma 类型

利用 Prisma 生成的类型，避免使用 `any`。

```typescript
// ❌ 使用 any
async function create(data: any) { ... }

// ✅ 使用 Prisma 类型
import { Prisma, Product } from '@prisma/client';

async function create(data: Prisma.ProductCreateInput): Promise<Product> { ... }
```

### JSON 字段处理

Prisma 可以直接接受 JSON 数据，无需 `JSON.parse(JSON.stringify())`。

```typescript
// ❌ 不必要的序列化
tags: data.tags ? JSON.parse(JSON.stringify(data.tags)) : Prisma.JsonNull,

// ✅ 直接使用
tags: data.tags ?? Prisma.JsonNull,
```

### 查询字段选择

使用 `selects.ts` 中的常量，保持一致性。

```typescript
// ❌ 内联定义
const user = await prisma.user.findUnique({
  where: { id: userId },
  select: { id: true, username: true, avatar: true, bio: true, ... },
});

// ✅ 使用常量
import { USER_PROFILE_SELECT } from '../common/selects';

const user = await prisma.user.findUnique({
  where: { id: userId },
  select: USER_PROFILE_SELECT,
});
```

### 并行查询

独立的数据库查询应并行执行。

```typescript
// ❌ 顺序执行
const user = await prisma.user.findUnique({ where: { id } });
const products = await prisma.product.findMany({ where: { userId: id } });

// ✅ 并行执行
const [user, products] = await Promise.all([
  prisma.user.findUnique({ where: { id } }),
  prisma.product.findMany({ where: { userId: id } }),
]);
```

## 分层架构

### 职责划分

| 层级 | 职责 | 不应包含 |
|------|------|----------|
| Routes | 路由定义、中间件绑定 | 业务逻辑 |
| Controller | 参数校验、调用 Service、返回响应 | 数据库操作 |
| Service | 业务逻辑、数据库操作 | HTTP 相关（req/res） |

### Controller 示例

```typescript
// ✅ 好的 Controller - 只做参数校验和调用 Service
export const ProductController = {
  create: asyncHandler(async (req: Request, res: Response) => {
    const userId = req.user!.userId;
    const data = req.body;

    // 参数校验
    if (!data.name?.trim()) return fail(res, '商品名称不能为空', 400);

    // 调用 Service
    const product = await ProductService.create(userId, data);

    return success(res, product, '创建成功', 201);
  }),
};
```

### Service 示例

```typescript
// ✅ 好的 Service - 包含业务逻辑和数据库操作
export const ProductService = {
  async create(userId: number, data: CreateProductData) {
    // 业务验证
    const category = await prisma.category.findUnique({
      where: { id: data.categoryId },
    });
    if (!category) throw badRequest('分类不存在');

    // 数据库操作
    return prisma.product.create({
      data: { ...data, userId, status: 'pending' },
    });
  },
};
```

## 注释规范

### 避免冗余注释

```typescript
// ❌ 冗余注释 - 函数名已说明
// 创建商品
async create(data: CreateProductData) { ... }

// ✅ 必要注释 - 解释 WHY
// 需要重新审核的字段（修改这些字段会触发审核流程）
const RE_AUDIT_FIELDS = ['name', 'description', 'categoryId', 'images', 'currentPrice'];
```

### 使用 JSDoc

为公共工具函数添加 JSDoc 注释。

```typescript
/**
 * 验证邮箱验证码
 * @param email 邮箱地址
 * @param code 验证码
 * @param type 验证码类型
 * @returns 验证码记录
 * @throws AppError 验证码无效或过期
 */
async verifyEmailCode(email: string, code: string, type: EmailCodeType): Promise<EmailCode>
```

## 常见问题

### Q: 什么时候使用 `Prisma.JsonNull`？

当 JSON 字段可能为空时，使用 `Prisma.JsonNull` 而非 `null`。

```typescript
tags: data.tags ?? Prisma.JsonNull,
```

### Q: BigInt 如何处理？

`response.ts` 会自动将 BigInt 转为字符串。Controller 中使用 `BigInt()` 解析 ID。

```typescript
const id = BigInt(req.params.id);
```

### Q: 如何处理事务？

使用 Prisma 的事务 API：

```typescript
await prisma.$transaction(async (tx) => {
  await tx.user.update({ ... });
  await tx.product.create({ ... });
});
```
