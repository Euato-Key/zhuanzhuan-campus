# 信用分模块

## 概述

信用分体系通过业务事件自动触发，无独立 API 端点。核心函数 `adjustCredit` 位于 `backend/src/common/credit.ts`。

## 评分规则

| 原因 | 变动 | 触发时机 |
|------|------|----------|
| order_completed | +3 | 买家确认收货，卖家加分 |
| good_review | +2 | 评价审核通过且 rating ≥ 4，卖家加分 |
| good_review_with_img | +3 | 好评且有图，卖家加分（含基础 +2） |
| cancel_after_pay | -1 | 买家付款后取消订单，买家扣分 |
| bad_review | -5 | 评价审核通过且 rating ≤ 2，卖家扣分 |
| order_refunded | -5 | 退货退款完成，卖家扣分 |
| report_warning | -10 | 管理员处理举报为警告，被举报人扣分 |
| product_banned | -15 | 管理员封禁商品，卖家扣分 |
| report_banned | -20 | 管理员处理举报为封禁，被举报人扣分 |

## 评分范围

- 最低：0
- 最高：150
- 默认：100

## 等级划分

| 筯围 | 等级 | 标签 | 颜色 |
|------|------|------|------|
| 120-150 | excellent | 优秀 | #4CAF50 |
| 100-119 | good | 良好 | #2196F3 |
| 80-99 | average | 一般 | #FF9800 |
| 60-79 | poor | 较差 | #E65100 |
| 0-59 | very_poor | 极差 | #F44336 |

## 通知机制

扣分时自动发送系统通知，告知用户扣分原因、扣分数额及当前信用分。

## 并发安全

`adjustCredit` 使用原子 SQL 操作（`GREATEST(0, LEAST(150, credit_score + delta))`），避免并发读后写丢失更新。

## 触发位置

| 模块 | 文件 | 事件 |
|------|------|------|
| order | `backend/src/modules/order/order.service.ts` | confirmReceive → order_completed, cancel → cancel_after_pay, confirmReturnReceived → order_refunded |
| review | `backend/src/modules/review/review.service.ts` | approve → good_review / good_review_with_img / bad_review |
| report | `backend/src/modules/report/report.service.ts` | handle → report_warning / report_banned |
| product | `backend/src/modules/product/product.service.ts` | ban → product_banned |

## 前端展示

- 工具函数：`frontend/src/utils/credit.ts` — `getCreditLevel(score)`
- 展示位置：ProfileCard.vue、detail.vue、userProfile.vue
- 等级标签 + 颜色通过 `el-tag` 组件展示
