# 收货地址模块（Address）

## 模块概述

收货地址模块负责用户收货地址的增删改查，支持设置默认地址。地址信息在订单创建时快照保存，后续修改地址不影响已有订单。

## 目录结构

```
src/modules/address/
├── address.routes.ts       # 路由定义
├── address.controller.ts   # 请求处理、参数校验
└── address.service.ts      # 业务逻辑
```

## API 接口

所有接口需携带 Access Token。

### 1. 获取地址列表

`GET /api/addresses`

返回当前用户的所有收货地址，默认地址排在最前。

### 2. 获取地址详情

`GET /api/addresses/:id`

### 3. 创建地址

`POST /api/addresses`

| 参数          | 类型    | 必填 | 说明                     |
| ------------- | ------- | ---- | ------------------------ |
| receiverName  | string  | 是   | 收货人姓名（1-50位）      |
| receiverPhone | string  | 是   | 收货人手机号（11位）      |
| province      | string  | 是   | 省份                     |
| city          | string  | 是   | 城市                     |
| district      | string  | 是   | 区县                     |
| street        | string  | 否   | 街道/乡镇                |
| detail        | string  | 是   | 详细地址                 |
| isDefault     | boolean | 否   | 是否设为默认地址          |

手机号需符合中国大陆手机号格式（`1[3-9]\d{9}`）。

### 4. 更新地址

`PUT /api/addresses/:id`

参数同创建地址，所有字段均为可选。设置 `isDefault: true` 会自动取消原默认地址。

### 5. 删除地址

`DELETE /api/addresses/:id`

### 6. 设置默认地址

`PUT /api/addresses/:id/default`

将指定地址设为默认，自动取消原默认地址。

---

## 地址快照机制

订单创建时，系统会将收货地址信息快照保存到 `addressSnapshot` 字段，包含：
- receiverName、receiverPhone
- province、city、district、street、detail

后续修改或删除地址不影响已有订单的收货信息。

---

## 响应格式

所有接口统一返回：

```json
{ "code": 200, "data": {}, "message": "success" }
```
