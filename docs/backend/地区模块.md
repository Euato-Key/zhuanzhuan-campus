# 地区模块（Region）

## 模块概述

地区模块提供省市区三级联动查询功能，数据来源于高德地图行政区域API。前端通过此接口获取地区数据，用于收货地址选择等场景。

## 目录结构

```
src/modules/region/
├── region.routes.ts       # 路由定义
├── region.controller.ts   # 请求处理
└── region.service.ts      # 高德API调用
```

## API 接口

所有接口为公开接口，无需登录。

### 1. 获取省份列表

`GET /api/regions/provinces`

返回中国所有省份的名称和行政区划代码。

### 2. 获取城市列表

`GET /api/regions/cities?adcode=xxx`

| 参数   | 类型   | 必填 | 说明               |
| ------ | ------ | ---- | ------------------ |
| adcode | string | 是   | 省份行政区划代码   |

返回指定省份下所有城市的名称和行政区划代码。

### 3. 获取区县列表

`GET /api/regions/districts?adcode=xxx`

| 参数   | 类型   | 必填 | 说明               |
| ------ | ------ | ---- | ------------------ |
| adcode | string | 是   | 城市行政区划代码   |

返回指定城市下所有区县的名称和行政区划代码。

---

## 高德API配置

需在 `backend/.env` 中配置 `AMAP_API_KEY`，否则接口调用会返回错误。

---

## 响应格式

所有接口统一返回：

```json
{ "code": 200, "data": {}, "message": "success" }
```
