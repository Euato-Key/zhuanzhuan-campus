# 创建超级管理员工具

## 功能说明

这是一个用于创建超级管理员账号的命令行工具，支持：

- 创建新的超级管理员账号
- 将现有用户提升为超级管理员
- 密码加密存储（bcrypt）
- 输入验证（邮箱格式、用户名长度、密码强度）

## 使用方法

### 方式一：交互式创建（推荐）

```bash
cd backend
npm run create-admin
```

按提示输入邮箱、用户名、密码即可。

### 方式二：命令行参数

```bash
npm run create-admin -- --email admin@example.com --username admin --password yourpassword
```

### 查看帮助

```bash
npm run create-admin -- --help
```

## 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `--email` | 邮箱地址（必填） | `admin@example.com` |
| `--username` | 用户名，2-50字符（必填） | `admin` |
| `--password` | 密码，至少6位（必填） | `yourpassword` |
| `--help, -h` | 显示帮助信息 | - |

## 使用示例

### 示例1：交互式创建

```bash

请输入用户名: superadmin

   用户名:   superadmin
```

### 示例2：提升现有用户

如果邮箱已存在但不是超级管理员，工具会自动提升权限：

```bash
$ npm run create-admin -- --email existing@campus.com --username test --password 123456

✅ 用户 testuser 已提升为超级管理员
```

### 示例3：已是超级管理员

```bash
$ npm run create-admin -- --email admin@campus.com --username test --password 123456

⚠️  该邮箱已是超级管理员
```

## 验证规则

- **邮箱**：必须符合标准邮箱格式
- **用户名**：长度 2-50 个字符
- **密码**：长度至少 6 位

## 注意事项

1. 运行前确保数据库已正确配置（`DATABASE_URL` 环境变量）
2. 运行前确保已执行 `npx prisma generate` 生成 Prisma Client
3. 超级管理员拥有系统最高权限，请谨慎创建
4. 建议在生产环境使用强密码

## 错误处理

| 错误信息 | 原因 | 解决方案 |
|----------|------|----------|
| `邮箱格式不正确` | 邮箱不符合格式要求 | 输入正确的邮箱地址 |
| `用户名长度需在2-50个字符之间` | 用户名太短或太长 | 调整用户名长度 |
| `密码长度至少6位` | 密码太短 | 使用更长的密码 |
| `用户名已被使用` | 用户名已存在 | 更换用户名 |
| `创建失败` | 数据库连接等问题 | 检查数据库配置 |
