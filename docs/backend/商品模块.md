# 商品模块

## 概述

商品模块负责校园二手商品的管理，包括商品的发布、编辑、上下架、审核等功能。

## 文件结构

```
backend/src/modules/product/
├── product.routes.ts      # 路由定义
├── product.controller.ts  # 控制器层
└── product.service.ts     # 服务层
```

## API 接口

### 公开接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/products` | 获取商品列表（支持筛选、排序、分页） |
| GET | `/api/products/user/:userId` | 获取用户在售商品（用户主页） |
| GET | `/api/products/:id` | 获取商品详情 |

### 用户接口（需登录）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/products` | 发布商品 |
| GET | `/api/products/my/list` | 获取我的商品列表 |
| GET | `/api/products/my/favorites` | 获取我的收藏列表（支持分页） |
| POST | `/api/products/:id/favorite` | 收藏商品 |
| DELETE | `/api/products/:id/favorite` | 取消收藏 |
| PUT | `/api/products/:id` | 更新商品 |
| PUT | `/api/products/:id/offline` | 下架商品 |
| PUT | `/api/products/:id/relist` | 重新上架 |
| DELETE | `/api/products/:id` | 删除商品 |

### 管理员接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/products/admin/list` | 获取所有商品列表 |
| PUT | `/api/products/admin/:id/approve` | 审核通过 |
| PUT | `/api/products/admin/:id/reject` | 审核拒绝 |
| PUT | `/api/products/admin/:id/ban` | 封禁商品 |
| PUT | `/api/products/admin/:id/unban` | 解封商品 |
| PUT | `/api/products/admin/:id/force-offline` | 强制下架 |

## 商品状态流转

```
                    ┌──────────────┐
                    │   pending    │ ← 新发布/重新提交
                    │  (待审核)     │
                    └──────┬───────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
              ▼            │            ▼
        ┌──────────┐       │      ┌─────────────┐
        │  active  │       │      │ audit_failed│
        │  (在售)   │       │      │ (审核失败)   │
        └────┬─────┘       │      └──────┬──────┘
             │             │             │
             ▼             │             │
        ┌──────────┐       │             │
        │ offline  │◄──────┘             │
        │ (已下架)  │                     │
        └──────────┘                     │
                                        │ 重新上架
                                        └────────────┘

              ┌──────────────────────────────┐
              │           banned             │
              │          (已封禁)             │
              └──────────────────────────────┘
```

## 枚举类型

### 新旧程度 (ItemCondition)

| Prisma 值 | 前端值 | 显示文本 |
|-----------|--------|----------|
| new | new | 全新 |
| ninety_nine_new | 99new | 99新 |
| ninety_five_new | 95new | 95新 |
| ninety_new | 90new | 9成新 |
| eighty_new | 80new | 8成新及以下 |

### 交易方式 (DeliveryType)

| 值 | 显示文本 |
|----|----------|
| self | 自提 |
| express | 快递 |
| both | 自提/快递 |

### 商品状态 (ProductStatus)

| 值 | 显示文本 |
|----|----------|
| pending | 待审核 |
| active | 在售 |
| offline | 已下架 |
| banned | 已封禁 |
| audit_failed | 审核失败 |

## 审核机制

### 审核次数限制

- 每个商品最多审核 3 次
- 审核失败 3 次后变为 `audit_failed` 状态，无法再次提交

### 需要重新审核的字段

修改以下字段会触发重新审核：
- name（商品名称）
- description（商品描述）
- categoryId（分类）
- images（图片）
- currentPrice（价格）

### 审核失败后重新上架

审核失败的商品可以修改后重新上架，但会消耗一次审核机会。

## 业务规则

1. **发布商品**：默认状态为 `pending`，等待审核
2. **自提商品**：必须填写自提地点
3. **图片限制**：主图最多 9 张，至少 1 张
4. **有效期**：可选 7/15/30 天，过期后自动下架
5. **删除限制**：有未完成订单的商品无法删除
6. **封禁商品**：无法编辑，需管理员解封

## 前端适配

### 新旧程度映射

前端使用 `99new`、`95new` 等格式，后端 Prisma 使用 `ninety_nine_new`、`ninety_five_new`。

映射关系定义在 `product.service.ts` 的 `ITEM_CONDITION_MAP` 中。

前端可通过 `getItemConditionLabel()` 函数获取显示文本。
