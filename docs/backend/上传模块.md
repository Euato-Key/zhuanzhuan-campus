# 上传模块（Upload）

## 模块概述

上传模块负责文件上传功能，通过阿里云 OSS STS 临时凭证或签名 URL 实现前端直传，减轻后端服务器压力。

## 目录结构

```
src/modules/upload/
├── upload.routes.ts       # 路由定义
├── upload.controller.ts   # 请求处理
└── upload.service.ts      # 转发到 FileService

src/services/
└── file.service.ts        # OSS 文件服务核心逻辑
```

## API 接口

### 1. 获取 STS 临时凭证

`POST /api/upload/sts-token`

需携带 Access Token。

| 参数 | 类型   | 必填 | 说明                                                   |
| ---- | ------ | ---- | ------------------------------------------------------ |
| type | string | 是   | 上传类型：`avatar` / `product` / `community` / `chat` |

返回阿里云 OSS STS 临时凭证，前端使用凭证直接上传文件到 OSS。

**响应示例：**

```json
{
  "code": 200,
  "data": {
    "accessKeyId": "STS.xxx",
    "accessKeySecret": "xxx",
    "securityToken": "xxx",
    "bucket": "zhuanzhuan-campus",
    "region": "oss-cn-hangzhou",
    "uploadPath": "avatars/1/temp/"
  },
  "message": "获取STS凭证成功"
}
```

### 2. 获取签名上传 URL

`POST /api/upload/signed-url`

需携带 Access Token。

| 参数     | 类型   | 必填 | 说明                                                   |
| -------- | ------ | ---- | ------------------------------------------------------ |
| type     | string | 是   | 上传类型：`avatar` / `product` / `community` / `chat` |
| filename | string | 是   | 文件名                                                 |

返回预签名的上传 URL，前端直接 PUT 文件内容到该 URL。

**响应示例：**

```json
{
  "code": 200,
  "data": {
    "url": "https://zhuanzhuan-campus.oss-cn-hangzhou.aliyuncs.com/...",
    "ossPath": "avatars/1/temp/xxx.jpg",
    "expires": 900
  },
  "message": "获取签名URL成功"
}
```

## 上传类型说明

| 类型      | 临时目录                    | 永久目录              | 用途         |
| --------- | --------------------------- | --------------------- | ------------ |
| avatar    | `avatars/{userId}/temp/`    | `avatars/{userId}/`   | 用户头像     |
| product   | `products/{userId}/temp/`   | `products/{userId}/`  | 商品图片     |
| community | `community/{userId}/temp/`  | `community/{userId}/` | 社区图片     |
| chat      | `chat/{userId}/temp/`       | `chat/{userId}/`      | 聊天图片     |

## 配置常量

| 常量 | 值 | 说明 |
|------|-----|------|
| MAX_AVATAR_SIZE_MB | 2 | 头像最大尺寸（MB） |
| MAX_IMAGE_SIZE_MB | 5 | 图片最大尺寸（MB） |
| MAX_AVATAR_COUNT | 1 | 头像最大数量 |
| MAX_PRODUCT_IMAGE_COUNT | 9 | 商品图片最大数量 |
| SIGNED_URL_EXPIRES_SECONDS | 900 | 签名URL有效期（秒） |
| STS_CREDENTIAL_EXPIRES_SECONDS | 3600 | STS凭证有效期（秒） |

## 上传流程

### 方式一：STS 临时凭证

1. 调用 `/api/upload/sts-token` 获取临时凭证
2. 前端使用 OSS SDK 或直接使用凭证上传文件
3. 上传成功后获得临时文件路径
4. 调用业务接口（如更新头像）将临时文件移动到永久目录

### 方式二：签名 URL

1. 调用 `/api/upload/signed-url` 获取签名 URL
2. 前端直接 PUT 文件内容到签名 URL
3. 上传成功后获得临时文件路径
4. 调用业务接口将临时文件移动到永久目录

---

## 安全特性

- **路径验证**：临时文件路径必须属于当前用户，防止越权访问
- **文件类型校验**：仅允许 jpg/jpeg/png/gif/webp 格式
- **文件大小限制**：头像 2MB，其他图片 5MB
- **随机文件名**：使用 crypto.randomBytes 生成随机后缀，避免文件名冲突和预测攻击
