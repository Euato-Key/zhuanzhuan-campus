# 评价模块

## 概述

评价模块提供用户之间基于交易订单的互评功能。买家和卖家可以在订单完成后相互评价，评价内容支持文字、图片和追加评价。评价需要经过管理员审核后才能公开展示。

## 文件结构

```
backend/src/
├── modules/review/
│   ├── review.routes.ts      # 路由定义
│   ├── review.controller.ts  # 控制器层（参数校验与解析）
│   └── review.service.ts     # 业务逻辑层（评价 CRUD、审核流程）
```

## 核心功能

- **创建评价**：订单完成后，买卖双方可相互评价
- **追加评价**：评价发布后可追加评价内容
- **删除评价**：评价发布者可删除自己的评价
- **评价查询**：支持按商品查询、查看我收到的/我发出的评价
- **管理审核**：管理员可审核评价（通过/拒绝）

## API 接口

### 用户接口（需登录）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/reviews` | 创建评价 |
| POST | `/api/reviews/:id/append` | 追加评价 |
| DELETE | `/api/reviews/:id` | 删除评价 |
| DELETE | `/api/reviews/:id/append` | 删除追加评价 |
| GET | `/api/reviews/received` | 我收到的评价 |
| GET | `/api/reviews/sent` | 我发出的评价 |
| GET | `/api/reviews/products/:productId` | 商品评价列表（公开，可选登录） |

### 管理员接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/reviews/admin/list` | 评价审核列表 |
| PUT | `/api/reviews/admin/:id/approve` | 审核通过 |
| PUT | `/api/reviews/admin/:id/reject` | 审核拒绝 |

## 请求与响应

### 创建评价

**请求**
```json
{
  "orderId": "12345678901234567890",
  "rating": 5,
  "content": "商品很好，卖家很热情",
  "images": ["products/123456.jpg"],
  "isAnonymous": false
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | string | 是 | 订单ID（BigInt转字符串） |
| rating | number | 是 | 评分1-5 |
| content | string | 否 | 评价内容 |
| images | string[] | 否 | 评价图片OSS路径 |
| isAnonymous | boolean | 否 | 是否匿名评价，默认false |

**响应（201）**
```json
{
  "code": 200,
  "data": {
    "id": "123",
    "orderId": "12345678901234567890",
    "type": "buyer_to_seller",
    "rating": 5,
    "content": "商品很好，卖家很热情",
    "images": ["products/123456.jpg"],
    "isAnonymous": false,
    "status": "pending",
    "createdAt": "2024-01-01T00:00:00.000Z"
  },
  "message": "评价成功"
}
```

### 追加评价

**请求**
```json
{
  "appendContent": "追加评价内容",
  "appendImages": ["products/追加图片.jpg"]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| appendContent | string | 是 | 追加内容 |
| appendImages | string[] | 否 | 追加图片 |

### 删除评价

删除评价时，会同时删除追加评价内容。

### 商品评价列表

**查询参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| rating | number | 按评分筛选（1-5） |
| hasImage | boolean | 只看有图片的评价 |
| sortBy | string | 排序方式：rating / time |
| sortOrder | string | 排序方向：asc / desc |
| page | number | 页码 |
| pageSize | number | 每页数量 |

**响应**
```json
{
  "code": 200,
  "data": {
    "list": [...],
    "total": 100,
    "page": 1,
    "pageSize": 10
  },
  "message": "success"
}
```

### 我收到的评价

**查询参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| type | string | 评价类型：buyer_to_seller / seller_to_buyer |
| rating | number | 按评分筛选 |
| page | number | 页码 |
| pageSize | number | 每页数量 |

### 管理员审核

**审核通过**
```
PUT /api/reviews/admin/:id/approve
```

**审核拒绝**
```json
{
  "rejectReason": "违规内容",
  "rejectAppend": false
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| rejectReason | string | 拒绝原因 |
| rejectAppend | boolean | 是否同时拒绝追加评价，默认false |

## 评价状态

| 状态 | 说明 |
|------|------|
| pending | 待审核 |
| approved | 已通过 |
| rejected | 已拒绝 |

## 评价类型

| 类型 | 说明 |
|------|------|
| buyer_to_seller | 买家评价卖家 |
| seller_to_buyer | 卖家评价买家 |

## 权限规则

| 操作 | 权限要求 |
|------|----------|
| 创建/追加/删除评价 | 订单相关方（买家或卖家） |
| 查看商品评价 | 公开（可选登录） |
| 查看我的评价 | 登录用户 |
| 审核评价 | 管理员 |
