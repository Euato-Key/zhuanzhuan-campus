# 配置模块

## 概述

配置模块 (`backend/src/config/`) 提供了环境变量管理和数据库连接配置，是后端应用的基础设施。

## 模块列表

| 文件 | 说明 |
|------|------|
| env.ts | 环境变量统一导出和启动验证 |
| prisma.ts | Prisma Client 单例 |

---

## env.ts - 环境变量管理

### 功能

统一管理和验证环境变量，避免在业务代码中直接访问 `process.env`。

### 设计原则

1. **集中管理**：所有环境变量通过 `env.xxx` 访问
2. **启动验证**：必需的环境变量在启动时检查，缺失时抛出错误
3. **类型安全**：提供 TypeScript 类型提示
4. **默认值**：为可选变量提供合理的默认值

### 环境变量列表

#### 必需变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `DATABASE_URL` | string | MySQL 连接字符串 |
| `JWT_ACCESS_SECRET` | string | Access Token 签名密钥（建议 ≥32 字符） |
| `JWT_REFRESH_SECRET` | string | Refresh Token 签名密钥（建议 ≥32 字符） |

#### 可选变量

| 变量名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `PORT` | number | 3000 | 服务端口 |
| `NODE_ENV` | string | development | 运行环境 |
| `JWT_ACCESS_EXPIRES_IN` | string | 60m | Access Token 有效期 |
| `JWT_REFRESH_EXPIRES_IN` | string | 30d | Refresh Token 有效期 |
| `QQ_EMAIL` | string | '' | QQ 邮箱地址 |
| `SMTP_AUTH_CODE` | string | '' | QQ 邮箱授权码 |
| `CLIENT_ORIGIN` | string | http://localhost:5173 | 前端地址（CORS） |
| `RATE_LIMIT_MAX` | number | 100 | 请求频率限制 |
| `OSS_REGION` | string | '' | OSS 区域 |
| `OSS_BUCKET` | string | '' | OSS 存储桶 |
| `OSS_ACCESS_KEY_ID` | string | '' | OSS Access Key |
| `OSS_ACCESS_KEY_SECRET` | string | '' | OSS Secret |
| `OSS_ROLE_ARN` | string | '' | OSS STS 角色 ARN |

### 使用方式

```typescript
import { env } from '../config/env';

// 访问环境变量
const port = env.PORT;
const dbUrl = env.DATABASE_URL;
const jwtSecret = env.JWT_ACCESS_SECRET;
```

### 启动验证

应用启动时会自动检查：

1. 必需变量是否存在
2. JWT 密钥长度是否足够（建议 ≥32 字符）

```typescript
// 启动时验证
validateRequiredEnvVars();

// 缺少必需变量时的错误
// Error: 缺少必需的环境变量: DATABASE_URL, JWT_ACCESS_SECRET

// 密钥长度不足时的警告
// [WARN] JWT_ACCESS_SECRET 长度小于 32 字符，建议使用更长的密钥以提高安全性
```

### .env 文件示例

```env
# 数据库

# JWT
JWT_ACCESS_SECRET="your-access-secret-key-at-least-32-chars"

JWT_ACCESS_EXPIRES_IN="60m"
JWT_REFRESH_EXPIRES_IN="30d"

# 邮件服务

# OSS（可选）

OSS_BUCKET="your-bucket-name"

OSS_ACCESS_KEY_SECRET="your-access-key-secret"

CLIENT_ORIGIN="http://localhost:5173"
```

## prisma.ts - 数据库连接

### 功能

创建和管理 Prisma Client 单例，确保整个应用共享同一个数据库连接。

### 为什么需要单例？

在开发模式下（使用 `tsx watch` 或 `nodemon`），文件变更会触发热重载。如果没有单例模式，每次重载都会创建新的 Prisma Client 实例，导致连接池耗尽。

### 实现原理

```typescript
import { PrismaClient } from '@prisma/client';

const globalForPrisma = globalThis as unknown as { prisma: PrismaClient };

export const prisma = globalForPrisma.prisma || new PrismaClient();

if (process.env.NODE_ENV !== 'production') {
  globalForPrisma.prisma = prisma;
}
```

- 在开发模式下，将 Prisma Client 存储在全局对象中
- 热重载时复用已有的实例，避免创建新连接
- 生产模式下正常创建实例

### 使用方式

```typescript
import { prisma } from '../config/prisma';

// 查询用户
const user = await prisma.user.findUnique({ where: { id: 1 } });

// 创建商品
const product = await prisma.product.create({ data: { ... } });

// 事务
await prisma.$transaction([
  prisma.order.create({ ... }),
  prisma.product.update({ ... }),
]);
```

### 连接管理

Prisma Client 会自动管理连接池：

- 按需创建连接
- 空闲连接自动回收
- 支持连接池配置（通过 DATABASE_URL 参数）

### 错误处理

```typescript
import { Prisma } from '@prisma/client';

try {
  await prisma.user.create({ data: { ... } });
} catch (error) {
  if (error instanceof Prisma.PrismaClientKnownRequestError) {
    // 处理 Prisma 特定错误
    if (error.code === 'P2002') {
      // 唯一约束冲突
    }
  }
}
```

## 最佳实践

### 环境变量安全

1. **不要提交 .env 文件**：添加到 `.gitignore`
2. **生产环境使用密钥管理服务**：如 AWS Secrets Manager、阿里云 KMS
3. **定期轮换密钥**：特别是 JWT 密钥和数据库密码

### 数据库连接

1. **使用连接池**：在 DATABASE_URL 中配置
   ```
   mysql://user:password@host:3306/db?connection_limit=10
   ```

2. **处理连接断开**：Prisma 会自动重连，但长时间空闲可能需要手动处理

3. **关闭连接**：应用退出时优雅关闭
   ```typescript
   process.on('SIGINT', async () => {
     await prisma.$disconnect();
     process.exit(0);
   });
   ```

## 常见问题

### Q: 修改 .env 后需要重启服务吗？

A: 是的，环境变量在启动时加载，修改后需要重启服务才能生效。

### Q: 如何在生产环境中设置环境变量？

A: 可以使用：
- Docker 环境变量（`docker run -e`）
- Kubernetes ConfigMap/Secret
- 云平台环境变量配置
- PM2 ecosystem.config.js

### Q: Prisma 连接池大小如何配置？

A: 默认连接池大小取决于数据库类型。MySQL 默认为 10。可以在 DATABASE_URL 中添加参数：
```
mysql://user:password@host:3306/db?connection_limit=20
```
