# 后端架构

## 技术栈

- Node.js + Express + TypeScript
- Prisma ORM（MySQL）
- JWT（jsonwebtoken）+ bcryptjs
- Nodemailer（QQ 邮箱 SMTP）
- Socket.io

## 目录结构

```
backend/src/
├── main.ts              # Express 入口，中间件注册，路由挂载
├── config/
│   ├── env.ts           # 环境变量统一导出
│   └── prisma.ts        # Prisma Client 单例
├── middlewares/
│   └── auth.ts          # JWT 鉴权中间件
├── modules/
│   └── auth/            # 认证模块
│       ├── auth.routes.ts
│       ├── auth.controller.ts
│       └── auth.service.ts
└── utils/
    ├── email.ts         # 邮件发送（QQ 邮箱 SMTP）
    └── response.ts      # 统一响应格式
```

## 模块分层

每个业务模块遵循三层结构：

| 层级         | 文件                | 职责                           |
| ------------ | ------------------- | ------------------------------ |
| Routes       | `*.routes.ts`       | 路由定义，中间件绑定           |
| Controller   | `*.controller.ts`   | 参数校验，调用 Service，返回响应|
| Service      | `*.service.ts`      | 业务逻辑，数据库操作           |

## 统一响应格式

```typescript
// 成功
{ code: 200, data: T, message: "success" }

// 失败
{ code: 400, data: null, message: "错误描述" }
```

通过 `utils/response.ts` 的 `success()` 和 `fail()` 函数统一处理。

## 鉴权中间件

`middlewares/auth.ts` 从 `Authorization: Bearer <token>` 提取并验证 JWT，将解码后的 `{ userId, role }` 挂载到 `req.user`。

需要鉴权的路由在 `routes` 中绑定 `authMiddleware`。

## 环境变量

通过 `config/env.ts` 统一读取，所有环境变量通过 `env.xxx` 访问，不在业务代码中直接读取 `process.env`。

关键变量：

| 变量名                | 说明                  |
| --------------------- | --------------------- |
| PORT                  | 服务端口（默认 3000） |
| DATABASE_URL          | MySQL 连接字符串      |
| JWT_ACCESS_SECRET     | Access Token 密钥     |
| JWT_REFRESH_SECRET    | Refresh Token 密钥    |
| QQ_EMAIL / SMTP_AUTH_CODE | QQ 邮箱 SMTP 配置 |
| CLIENT_ORIGIN         | 前端地址（CORS 白名单）|

## 运行

```bash
cd backend
npm run dev    # 开发模式（tsx watch）
npm run build  # 编译
npm start      # 生产模式
```
