# 通知模块

## 模块概述

通知模块为平台提供站内通知功能，支持多种通知类型的创建、查询、已读标记和删除，并通过 WebSocket 实时推送。

## 文件结构

```
src/modules/notification/
├── notification.controller.ts   # 控制器 - 请求处理与参数校验
├── notification.service.ts      # 服务层 - 业务逻辑与 WebSocket 推送
├── notification.routes.ts       # 路由定义
├── notification.socket.ts       # Socket.io 连接初始化
└── notification.types.ts        # TypeScript 类型定义
```

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/notifications` | 获取通知列表（支持类型筛选、分页） |
| GET | `/api/notifications/unread-count` | 获取未读通知数量（总数 + 按类型分组） |
| GET | `/api/notifications/:id` | 获取通知详情（未读自动标记已读） |
| PUT | `/api/notifications/:id/read` | 标记通知已读 |
| PUT | `/api/notifications/read-all` | 批量标记已读（支持按类型筛选） |
| DELETE | `/api/notifications/:id` | 删除通知（仅已读可删） |

详细接口文档见 [OpenAPI 文档](../openapi/notification.json)

## 通知类型

| 类型 | 枚举值 | 说明 |
|------|--------|------|
| 系统通知 | `system` | 账号安全、系统公告等 |
| 商品通知 | `product` | 商品审核结果、封禁/解封等 |
| 订单通知 | `order` | 订单状态变更、支付/发货/收货提醒等 |
| 聊天通知 | `chat` | 聊天相关通知 |
| 评价通知 | `review` | 收到评价、追评、审核结果等 |
| 互动通知 | `interaction` | 收藏商品变动、求购评论/回复/点赞等 |

## 关联对象类型

| 类型 | 枚举值 | 说明 |
|------|--------|------|
| 订单 | `order` | relatedId 为订单 ID（BigInt） |
| 商品 | `product` | relatedId 为商品 ID（BigInt） |
| 评价 | `review` | relatedId 为评价 ID |
| 用户 | `user` | relatedId 为用户 ID |
| 求购 | `want_buy` | relatedId 为求购帖 ID |

## WebSocket 推送

### 事件

| 事件名 | 方向 | 数据 | 说明 |
|--------|------|------|------|
| `notification:new` | Server → Client | Notification 对象 | 新通知实时推送 |
| `notification:unread_count` | Server → Client | `{ total, byType }` | 未读数更新推送 |

### 连接初始化

用户通过 Socket.io 连接后，`registerNotificationSocket()` 会自动推送当前未读数。

### 房间

用户加入 `user_${userId}` 房间，通知推送至该房间。

## 业务规则

1. **自动已读**：查看通知详情时，未读通知自动标记为已读
2. **删除限制**：未读通知不可删除，需先标记已读
3. **权限校验**：只能操作自己的通知
4. **实时推送**：通知创建后通过 WebSocket 实时推送给用户
5. **未读数同步**：每次通知状态变更后推送最新未读数
