# 公共工具模块

## 概述

公共工具模块 (`backend/src/common/`) 提供了后端通用的工具函数和类，用于统一错误处理、异步路由包装、密码处理、验证码生成等。

## 模块列表

| 文件 | 说明 |
|------|------|
| errors.ts | 自定义错误类 |
| asyncHandler.ts | 异步路由处理器包装 |
| password.ts | 密码哈希工具 |
| verification.ts | 验证码工具 |
| pagination.ts | 分页工具 |
| token.ts | Refresh Token 工具 |
| selects.ts | 数据库查询字段常量 |
| validation.ts | 参数验证工具 |
| cleanup.ts | 过期数据清理定时任务 |

---

## errors.ts - 错误处理

### AppError 类

统一的错误类，避免重复的 `throw Object.assign(new Error(), { statusCode })` 模式。

```typescript
import { AppError } from '../common/errors';

// 基础用法
throw new AppError('错误信息', 400);

// 快捷方法
import { badRequest, notFound, unauthorized, forbidden, conflict } from '../common/errors';

throw badRequest('参数错误');        // 400
throw unauthorized('未登录');        // 401
throw forbidden('无权限');           // 403
throw notFound('资源不存在');        // 404
throw conflict('用户名已存在');      // 409
```

### 错误属性

| 属性 | 类型 | 说明 |
|------|------|------|
| message | string | 错误信息 |
| statusCode | number | HTTP 状态码 |
| isOperational | boolean | 是否为可操作错误（用于区分程序错误） |

## asyncHandler.ts - 异步处理器

包装异步路由处理器，自动捕获异常并返回错误响应。

### 使用方式

```typescript
import { asyncHandler } from '../common/asyncHandler';
import { success } from '../utils/response';

// 在路由中使用
router.post('/example', asyncHandler(async (req, res) => {
  const result = await SomeService.doSomething(req.body);
  return success(res, result);
}));

// 或在 controller 中使用
export const SomeController = {
  create: asyncHandler(async (req: Request, res: Response) => {
    const data = req.body;
    const result = await SomeService.create(data);
    return success(res, result, '创建成功', 201);
  }),
};
```

### 优势

- 消除每个 controller 方法中重复的 try-catch
- 统一错误响应格式
- 减少约 80 行重复代码

## password.ts - 密码工具

统一的密码哈希和验证工具。

### API

```typescript
import { PasswordUtil } from '../common/password';

// 哈希密码
const hash = await PasswordUtil.hash('password123');

// 验证密码
const isValid = await PasswordUtil.verify('password123', hash);

// 验证密码强度
const error = PasswordUtil.validate('pwd');
if (error) {
  // error = '密码长度不能少于6位'
}
```

### 配置

- 盐值轮数：10（bcrypt 默认推荐值）
- 最小密码长度：6

## verification.ts - 验证码工具

安全的验证码生成和验证工具。

### 验证码类型枚举

```typescript
enum EmailCodeType {
  REGISTER = 'register',
  LOGIN = 'login',
  RESET_PASSWORD = 'reset_password',
  CHANGE_EMAIL = 'change_email',
}
```

### API

```typescript
import { VerificationUtil, EmailCodeType } from '../common/verification';

// 生成验证码（使用加密安全随机数）
const code = VerificationUtil.generateCode();  // 例如: "847293"

// 验证邮箱验证码
const emailCode = await VerificationUtil.verifyEmailCode(
  'user@example.com',
  '847293',
  EmailCodeType.REGISTER
);

// 标记验证码已使用
await VerificationUtil.markCodeUsed(emailCode.id);

// 创建验证码记录（通常在发送邮件前调用）
const code = await VerificationUtil.createCode('user@example.com', EmailCodeType.REGISTER);
```

### 安全特性

1. **加密安全随机数**：使用 `crypto.randomInt()` 而非 `Math.random()`
2. **时序攻击防护**：使用 `crypto.timingSafeEqual()` 比较验证码
3. **自动过期检查**：验证时自动检查 `expiresAt`

## pagination.ts - 分页工具

统一的分页计算逻辑。

### API

```typescript
import { PaginationUtil } from '../common/pagination';

// 计算分页参数
const { skip, take, page, pageSize } = PaginationUtil.getPagination({
  page: 2,
  pageSize: 20,
  maxPageSize: 100,  // 可选，默认 50
});

// 构建分页响应
const response = PaginationUtil.buildResponse(list, total, page, pageSize);
// 返回: { list, total, page, pageSize, totalPages }

// 从请求查询参数解析
const pagination = PaginationUtil.fromQuery(req.query);
```

### 默认值

- 默认页码：1
- 默认每页数量：10
- 最大每页数量：50

## token.ts - Token 工具

Refresh Token 管理工具。

### API

```typescript
import { TokenUtil } from '../common/token';

// 撤销用户所有未过期的 refresh token
await TokenUtil.revokeAllUserTokens(userId);

// 撤销单个 refresh token
await TokenUtil.revokeToken(tokenHash, userId);

// 清理过期的 refresh tokens（可定期执行）
const count = await TokenUtil.cleanupExpiredTokens();
```

### 使用场景

- 用户修改密码后：撤销所有 token
- 用户更换邮箱后：撤销所有 token
- 用户退出登录：撤销当前 token
- 定时任务：清理过期 token

## validation.ts - 参数验证工具

统一的参数验证工具，避免在多个地方重复验证逻辑。

### API

```typescript
import { ValidationUtil } from '../common/validation';

// 验证密码长度
ValidationUtil.validatePassword(password);  // 不足6位抛出 badRequest

// 验证用户名长度
ValidationUtil.validateUsername(username);  // 2-50位

// 验证分类名称
ValidationUtil.validateCategoryName(name);  // 不超过50字符

// 验证邮箱格式
ValidationUtil.validateEmail(email);  // 检查邮箱格式

// 要求非空字符串
const value = ValidationUtil.requireNonEmptyString(req.body.reason, '拒绝原因');

// 解析 ID 参数
const userId = ValidationUtil.parseIdParam(req.params.id, '用户ID');

// 解析 BigInt 参数
const productId = ValidationUtil.parseBigIntParam(req.params.id, '商品ID');

// 获取当前登录用户ID（未登录抛出 unauthorized）
const userId = ValidationUtil.requireUserId(req);

// 获取请求元信息
const { userAgent, ip } = ValidationUtil.getRequestMeta(req);
```

### 使用场景

- Controller 层参数验证
- 路由参数解析
- 表单字段验证

## cleanup.ts - 过期数据清理

定时清理过期数据的后台任务。

### API

```typescript
import { CleanupService, startCleanupJobs } from '../common/cleanup';

// 启动所有清理任务（在 main.ts 中调用）
startCleanupJobs();

// 手动执行清理
await CleanupService.cleanupExpiredRefreshTokens();
await CleanupService.cleanupExpiredEmailCodes();
```

### 清理任务

| 任务 | 执行时间 | 清理内容 |
|------|----------|----------|
| Refresh Token 清理 | 每天凌晨 3 点 | 过期和已撤销的 token |
| Email Code 清理 | 每天凌晨 4 点 | 过期和已使用的验证码 |
| OSS 临时文件清理 | 每天凌晨 5 点 | 超过 30 天的临时上传文件 |

## 最佳实践

### 错误处理

```typescript
// ❌ 不推荐
throw Object.assign(new Error('用户不存在'), { statusCode: 404 });

// ✅ 推荐
import { notFound } from '../common/errors';
throw notFound('用户不存在');
```

### 异步路由

```typescript
// ❌ 不推荐
async function create(req: Request, res: Response) {
  try {
    const result = await Service.create(req.body);
    return success(res, result);
  } catch (err: any) {
    return fail(res, err.message, err.statusCode || 500);
  }
}

// ✅ 推荐
const create = asyncHandler(async (req: Request, res: Response) => {
  const result = await Service.create(req.body);
  return success(res, result);
});
```

### 分页

```typescript
// ❌ 不推荐
const page = query.page ?? 1;
const pageSize = Math.min(query.pageSize ?? 10, 50);
const skip = (page - 1) * pageSize;

// ✅ 推荐
const { skip, take, page, pageSize } = PaginationUtil.getPagination(query);
```
