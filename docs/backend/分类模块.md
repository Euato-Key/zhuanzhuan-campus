# 分类模块（Category）

## 模块概述

分类模块负责商品分类的管理，支持两级分类结构（父分类 + 子分类）。提供分类的增删改查功能，以及树形结构和平铺列表两种查询方式。

## 目录结构

```
src/modules/category/
├── category.routes.ts       # 路由定义
├── category.controller.ts   # 请求处理、参数校验
└── category.service.ts      # 业务逻辑
```

## API 接口

### 公开接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/categories/tree` | 获取分类树形结构 |
| GET | `/api/categories/list` | 获取分类平铺列表 |
| GET | `/api/categories/:id` | 获取分类详情 |

### 管理员接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/categories` | 创建分类 |
| PUT | `/api/categories/:id` | 更新分类 |
| DELETE | `/api/categories/:id` | 删除分类 |

## 分类树形结构

返回嵌套的父子分类结构：

```json
[
  {
    "id": 1,
    "name": "数码产品",
    "parentId": null,
    "icon": null,
    "sort": 100,
    "children": [
      {
        "id": 2,
        "name": "手机",
        "parentId": 1,
        "icon": null,
        "sort": 0,
        "children": []
      }
    ]
  }
]
```

## 业务规则

### 分类层级

- 最多支持两级分类（父分类 + 子分类）
- 子分类不能再有子分类（不支持三级）

### 创建分类

- 分类名称在同一层级内不能重复
- 如果指定 `parentId`，父分类必须是一级分类
- `sort` 默认为 0，数值越大排序越靠前

### 更新分类

- 不能将自己设为父分类
- 如果要变为子分类，当前分类下不能已有子分类
- 修改父分类时，新父分类必须是一级分类

### 删除分类

- 分类下有商品时无法删除
- 分类下有子分类时无法删除
