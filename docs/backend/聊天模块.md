# 聊天模块（Chat）

## 模块概述

聊天模块负责用户间的实时通信，支持文本、图片、商品卡片、订单卡片四种消息类型。基于 Socket.io 实现 WebSocket 实时推送，同时提供 REST API 作为消息收发的补充。内置黑名单机制和快捷回复模板功能。

## 目录结构

```
src/modules/chat/
├── chat.routes.ts       # 路由定义
├── chat.controller.ts   # 请求处理、参数校验
├── chat.service.ts      # 业务逻辑
├── chat.socket.ts       # Socket.io 事件处理
└── chat.types.ts        # 类型定义
```

## WebSocket 集成

Socket.io 服务器在 `src/config/socket.ts` 中初始化，挂载到与 Express 共享的 HTTP 服务器上。连接时需在 `handshake.auth.token` 中传入 JWT Access Token 进行鉴权。

### 房间机制

- `user_${userId}` — 用户个人房间，用于接收定向推送（新消息、已读回执、拉黑通知等）
- `conversation_${conversationId}` — 会话房间，进入会话视图时加入，离开时退出

### 客户端→服务端事件

| Event | Payload | 说明 |
|-------|---------|------|
| `chat:send_message` | `{ conversationId, type, content }` | 实时发送消息 |
| `chat:typing` | `{ conversationId }` | 正在输入 |
| `chat:stop_typing` | `{ conversationId }` | 停止输入 |
| `chat:mark_read` | `{ conversationId }` | 标记已读 |
| `chat:join_conversation` | `{ conversationId }` | 进入会话视图 |
| `chat:leave_conversation` | `{ conversationId }` | 离开会话视图 |

### 服务端→客户端事件

| Event | Payload | 目标 | 说明 |
|-------|---------|------|------|
| `chat:new_message` | MessageItem | 双方 `user_${id}` | 新消息通知 |
| `chat:message_read` | `{ conversationId, readBy, readCount }` | `user_${senderId}` | 已读回执 |
| `chat:typing_indicator` | `{ conversationId, userId }` | `conversation_${id}` | 输入中指示 |
| `chat:stop_typing_indicator` | `{ conversationId, userId }` | `conversation_${id}` | 停止输入 |
| `chat:conversation_updated` | ConversationListItem | 双方 `user_${id}` | 会话列表更新 |
| `chat:online_status` | `{ userId, online }` | 全局广播 | 用户上下线 |
| `chat:blocked` | `{ blockedByUserId }` | `user_${blockedId}` | 被拉黑通知 |
| `chat:unblocked` | `{ unblockedByUserId }` | `user_${unblockedId}` | 被解除拉黑通知 |
| `chat:error` | `{ message }` | 单个 socket | 错误响应 |

## REST API 接口

所有接口需携带 Access Token。

### 1. 获取会话列表

`GET /api/chat/conversations`

| 参数     | 类型    | 必填 | 说明                    |
| -------- | ------- | ---- | ----------------------- |
| page     | integer | 否   | 页码（默认1）            |
| pageSize | integer | 否   | 每页数量（默认10，最大50）|

返回会话列表，按更新时间倒序，包含对方用户信息、最新消息摘要、未读消息数。

### 2. 创建/获取会话

`POST /api/chat/conversations`

| 参数          | 类型    | 必填 | 说明       |
| ------------- | ------- | ---- | ---------- |
| targetUserId  | integer | 是   | 对方用户ID |

如已存在会话则返回现有会话。不能和自己聊天，不能和被拉黑的用户创建会话。

### 3. 获取会话详情

`GET /api/chat/conversations/:id`

| 参数 | 类型    | 必填 | 说明   |
| ---- | ------- | ---- | ------ |
| id   | integer | 是   | 会话ID |

### 4. 获取消息历史

`GET /api/chat/conversations/:id/messages`

| 参数     | 类型    | 必填 | 说明                                    |
| -------- | ------- | ---- | --------------------------------------- |
| id       | integer | 是   | 会话ID（路径参数）                        |
| page     | integer | 否   | 页码（默认1）                             |
| pageSize | integer | 否   | 每页数量（默认20，最大50）                 |
| before   | string  | 否   | 游标：返回ID小于此值的消息（用于无限滚动）  |

消息按创建时间升序排列（最旧在前）。

### 5. 发送消息

`POST /api/chat/conversations/:id/messages`

| 参数    | 类型   | 必填 | 说明                                           |
| ------- | ------ | ---- | ---------------------------------------------- |
| id      | integer| 是   | 会话ID（路径参数）                               |
| type    | string | 是   | 消息类型：text/image/product/order              |
| content | string | 是   | 消息内容（见下方说明）                           |

**消息内容说明：**
- `text`：纯文本内容，最多2000字符
- `image`：图片URL，最多500字符，需以 `/` 或 `http` 开头
- `product`：JSON字符串 `{"productId":"123"}`，服务端查库构造完整卡片。商品须在售中且属于当前会话的某一方（我的宝贝或对方宝贝）
- `order`：JSON字符串 `{"orderId":"456"}`，服务端查库构造完整卡片。订单不可为已取消，且买卖双方必须恰好是当前会话的两个人

### 6. 标记消息已读

`PUT /api/chat/conversations/:id/messages/read`

将会话中对方发送的未读消息全部标记为已读，并通过 WebSocket 通知对方。

### 7. 搜索消息

`GET /api/chat/conversations/:id/messages/search`

| 参数    | 类型   | 必填 | 说明         |
| ------- | ------ | ---- | ------------ |
| id      | integer| 是   | 会话ID（路径）|
| keyword | string | 是   | 搜索关键词（最多100字符）|
| page    | integer| 否   | 页码          |
| pageSize| integer| 否   | 每页数量      |

使用 MySQL LIKE 模糊搜索。

### 8. 获取黑名单列表

`GET /api/chat/blacklist`

| 参数     | 类型    | 必填 | 说明                    |
| -------- | ------- | ---- | ----------------------- |
| page     | integer | 否   | 页码（默认1）            |
| pageSize | integer | 否   | 每页数量（默认10，最大50）|

### 9. 拉黑用户

`POST /api/chat/blacklist`

| 参数           | 类型    | 必填 | 说明         |
| -------------- | ------- | ---- | ------------ |
| blockedUserId  | integer | 是   | 要拉黑的用户ID |

拉黑后双方无法互相发送消息。重复拉黑返回409。

### 10. 解除拉黑

`DELETE /api/chat/blacklist/:blockedUserId`

| 参数           | 类型    | 必填 | 说明           |
| -------------- | ------- | ---- | -------------- |
| blockedUserId  | integer | 是   | 要解除拉黑的用户ID |

### 11. 检查拉黑状态

`GET /api/chat/blacklist/check`

| 参数   | 类型    | 必填 | 说明       |
| ------ | ------- | ---- | ---------- |
| userId | integer | 是   | 对方用户ID |

返回 `{ isBlocked, blockedByMe, blockedByOther }`，任一方拉黑则 `isBlocked` 为 true。

### 12. 获取快捷回复列表

`GET /api/chat/quick-replies`

不分页，按 sort 升序排列。

### 13. 创建快捷回复

`POST /api/chat/quick-replies`

| 参数    | 类型    | 必填 | 说明                     |
| ------- | ------- | ---- | ------------------------ |
| content | string  | 是   | 快捷回复内容（最多255字） |
| sort    | integer | 否   | 排序值（默认0）           |

### 14. 修改快捷回复

`PUT /api/chat/quick-replies/:id`

| 参数    | 类型    | 必填 | 说明                     |
| ------- | ------- | ---- | ------------------------ |
| id      | integer | 是   | 快捷回复ID（路径参数）    |
| content | string  | 否   | 快捷回复内容（最多255字） |
| sort    | integer | 否   | 排序值                   |

### 15. 删除快捷回复

`DELETE /api/chat/quick-replies/:id`

| 参数 | 类型    | 必填 | 说明                  |
| ---- | ------- | ---- | --------------------- |
| id   | integer | 是   | 快捷回复ID（路径参数） |

### 16. 批量更新排序

`PUT /api/chat/quick-replies/sort`

| 参数       | 类型  | 必填 | 说明                           |
| ---------- | ----- | ---- | ------------------------------ |
| items      | array | 是   | `[{ id: 1, sort: 0 }, ...]`   |

### 17. 获取议价模板

`GET /api/chat/bargain-template/:productId`

| 参数      | 类型   | 必填 | 说明                         |
| --------- | ------ | ---- | ---------------------------- |
| productId | string | 是   | 商品ID（路径参数，BigInt字符串）|

仅当商品支持议价时返回模板消息，如 `"这个商品【XX】可以优惠吗？我出XX元"`。

## 消息类型与内容格式

| type    | content 格式 | 说明 |
|---------|-------------|------|
| text    | 纯文本字符串 | 最多2000字符 |
| image   | 图片URL字符串 | 最多500字符 |
| product | JSON: `{"productId":"123","name":"...","image":"...","price":99.9}` | 服务端构造 |
| order   | JSON: `{"orderId":"456","orderNo":"...","productName":"...","productImage":"...","status":"..."}` | 服务端构造 |

> 客户端发送 product/order 类型时，content 只需包含 ID：`{"productId":"123"}` 或 `{"orderId":"456"}`，服务端会查库填充完整卡片数据。

---

## 响应格式

所有接口统一返回：

```json
{ "code": 200, "data": {}, "message": "success" }
```
