# 订单模块（Order）

## 模块概述

订单模块负责商品交易全流程管理，包括下单、支付、发货、收货、退货等。支持快递配送和校内自提两种交易方式，内置库存锁定机制防止超卖。

## 目录结构

```
src/modules/order/
├── order.routes.ts       # 路由定义
├── order.controller.ts   # 请求处理、参数校验
└── order.service.ts      # 业务逻辑
```

## API 接口

所有接口需携带 Access Token。

### 1. 创建订单

`POST /api/orders`

| 参数          | 类型   | 必填 | 说明                       |
| ------------- | ------ | ---- | -------------------------- |
| productId     | string | 是   | 商品ID                     |
| quantity      | integer| 是   | 购买数量（最少1）           |
| deliveryType  | string | 是   | 交易方式：self/express      |
| addressId     | integer| 否   | 收货地址ID（快递方式必填）  |
| pickupInfo    | object | 否   | 自提信息（自提方式必填）    |
| pickupInfo.address | string | 是 | 自提地点              |
| pickupInfo.time    | string | 否 | 自提时间段            |

创建订单时会锁定库存30分钟，超时未支付自动取消并释放库存。

### 2. 获取订单列表

`GET /api/orders`

| 参数     | 类型   | 必填 | 说明                                  |
| -------- | ------ | ---- | ------------------------------------- |
| page     | integer| 否   | 页码（默认1）                          |
| pageSize | integer| 否   | 每页数量（默认10，最大50）             |
| status   | string | 否   | 订单状态筛选                           |
| role     | string | 否   | 角色筛选：buyer/seller                  |

### 3. 获取订单详情

`GET /api/orders/:id`

买家或卖家可查看订单详情，包含商品信息、收货地址、物流信息等。

### 4. 支付订单

`POST /api/orders/:id/pay`

| 参数          | 类型   | 必填 | 说明                     |
| ------------- | ------ | ---- | ------------------------ |
| paymentMethod | string | 是   | 支付方式：wechat/alipay   |

模拟支付，支付成功后扣减库存并删除库存锁。

### 5. 取消订单

`POST /api/orders/:id/cancel`

| 参数   | 类型   | 必填 | 说明       |
| ------ | ------ | ---- | ---------- |
| reason | string | 否   | 取消原因   |

待支付订单取消释放库存锁，已支付订单取消恢复库存。买家和卖家均可取消。

### 6. 卖家发货

`POST /api/orders/:id/ship`

| 参数          | 类型   | 必填 | 说明       |
| ------------- | ------ | ---- | ---------- |
| expressCompany| string | 是   | 快递公司   |
| expressNo     | string | 是   | 快递单号   |

仅快递配送订单可发货。

### 7. 卖家确认买家取货

`POST /api/orders/:id/confirm-pickup`

仅自提订单可用，卖家确认买家已取货。

### 8. 买家确认收货

`POST /api/orders/:id/confirm-receive`

快递订单和自提订单均可确认收货，订单变为已完成。

### 9. 申请退货

`POST /api/orders/:id/return`

| 参数   | 类型   | 必填 | 说明       |
| ------ | ------ | ---- | ---------- |
| reason | string | 是   | 退货原因   |

仅已完成订单可申请退货，需在确认收货后14天内。最多申请3次。

### 10. 卖家审核退货

`POST /api/orders/:id/return/review`

| 参数        | 类型    | 必填 | 说明             |
| ----------- | ------- | ---- | ---------------- |
| approved    | boolean | 是   | 是否同意退货     |
| rejectReason| string  | 否   | 拒绝原因（拒绝时必填）|

### 11. 买家填写退货快递

`POST /api/orders/:id/return/express`

| 参数    | 类型   | 必填 | 说明     |
| ------- | ------ | ---- | -------- |
| company | string | 是   | 快递公司 |
| expressNo| string| 是   | 快递单号 |

退货审核通过后填写。

### 12. 卖家确认收到退货

`POST /api/orders/:id/return/confirm`

确认后订单变为已退款，库存恢复。

---

## 订单状态流转

```
pending_payment → pending_ship (快递) / pending_pickup (自提)
                → cancelled

pending_ship → pending_receive → completed → returning → refunded
            → cancelled

pending_pickup → pending_confirm → completed → returning → refunded
              → cancelled
```

## 库存锁定机制

- 创建订单时锁定库存30分钟
- 支付成功后扣减实际库存并删除锁
- 取消订单时释放锁
- 定时任务每5分钟清理过期锁，自动取消超时未支付订单
