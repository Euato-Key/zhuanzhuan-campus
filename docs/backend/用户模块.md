# 用户模块（User）

## 模块概述

用户模块负责用户资料管理，包括修改用户名、学校、校区、手机号、简介、头像，以及修改密码和更换邮箱等功能。

## 目录结构

```
src/modules/user/
├── user.routes.ts       # 路由定义
├── user.controller.ts   # 请求处理、参数校验
└── user.service.ts      # 业务逻辑
```

## API 接口

### 1. 更新用户资料

`PUT /api/user/profile`

需携带 Access Token。

| 参数    | 类型   | 必填 | 说明                |
| ------- | ------ | ---- | ------------------- |
| username| string | 否   | 用户名（2-50位）     |
| school  | string | 否   | 学校名称            |
| campus  | string | 否   | 校区名称            |
| phone   | string | 否   | 手机号（需符合格式） |
| bio     | string | 否   | 个人简介            |

用户名修改时会检查是否已被其他用户使用。手机号需符合中国大陆手机号格式（`1[3-9]\d{9}`）。

### 2. 修改密码

`POST /api/user/change-password`

需携带 Access Token。

| 参数        | 类型   | 必填 | 说明            |
| ----------- | ------ | ---- | --------------- |
| oldPassword | string | 是   | 当前密码        |
| newPassword | string | 是   | 新密码（至少6位）|

修改成功后，所有 Refresh Token 自动吊销，用户需重新登录。

### 3. 更换邮箱

`POST /api/user/change-email`

需携带 Access Token。

| 参数     | 类型   | 必填 | 说明                     |
| -------- | ------ | ---- | ------------------------ |
| newEmail | string | 是   | 新邮箱地址               |
| code     | string | 是   | 新邮箱的验证码（type=change_email）|

需先调用 `/api/auth/send-code`（type=change_email，email=newEmail）获取验证码。

更换成功后，所有 Refresh Token 自动吊销，用户需重新登录。

### 4. 更新头像

`POST /api/user/avatar`

需携带 Access Token。

| 参数     | 类型   | 必填 | 说明                          |
| -------- | ------ | ---- | ----------------------------- |
| tempPath | string | 是   | OSS 临时文件路径（上传后获取）|

用户需先通过上传模块获取临时文件路径，再调用此接口将头像从临时目录移动到永久目录。

### 5. 获取用户公开资料

`GET /api/user/:id/profile`

公开接口，无需登录。

返回指定用户的公开资料（用户名、头像、简介、学校、校区、信用分、注册时间）。

## 公共工具使用

用户模块使用了以下公共工具：

| 工具 | 用途 |
|------|------|
| `PasswordUtil` | 密码哈希和验证 |
| `VerificationUtil` | 验证码验证 |
| `TokenUtil` | Refresh Token 撤销 |
| `USER_PROFILE_SELECT` | 用户完整资料字段选择 |
| `USER_PUBLIC_PROFILE_SELECT` | 用户公开资料字段选择 |
| `AppError` | 统一错误处理 |
| `asyncHandler` | 异步路由包装 |

---

## 响应格式

所有接口统一返回：

```json
{ "code": 200, "data": {}, "message": "success" }
```
