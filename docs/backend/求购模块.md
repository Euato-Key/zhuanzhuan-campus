# 求购模块

## 概述

求购模块提供用户发布求购信息的功能，其他用户可以浏览并评论这些求购贴。求购贴类似于"帮忙代购"或"求转让"的需求发布，适用于用户想要购买某个商品但找不到合适卖家时发布需求。

## 文件结构

```
backend/src/
├── modules/want-buy/
│   ├── want-buy.routes.ts      # 路由定义
│   ├── want-buy.controller.ts  # 控制器层（参数校验与解析）
│   └── want-buy.service.ts     # 业务逻辑层（求购贴 CRUD、评论管理）
```

## 核心功能

- **求购贴管理**：发布、编辑、删除、查看求购贴
- **状态管理**：开启、关闭、标记已找到、重新开启
- **评论系统**：求购贴下可发表评论，支持嵌套回复
- **点赞功能**：可对评论进行点赞/取消点赞
- **管理功能**：管理员可删除违规求购贴和评论

## API 接口

### 公开接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/want-buy` | 获取求购贴列表 |
| GET | `/api/want-buy/user/:userId` | 获取用户发布的求购贴 |
| GET | `/api/want-buy/:id` | 获取求购贴详情 |
| GET | `/api/want-buy/:id/comments` | 获取评论列表 |

### 需要登录的接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/want-buy/my/list` | 获取我的求购贴列表 |
| POST | `/api/want-buy` | 发布求购贴 |
| PUT | `/api/want-buy/:id` | 更新求购贴 |
| DELETE | `/api/want-buy/:id` | 删除求购贴 |
| PUT | `/api/want-buy/:id/found` | 标记为已找到 |
| PUT | `/api/want-buy/:id/close` | 关闭求购贴 |
| PUT | `/api/want-buy/:id/reopen` | 重新开启 |
| POST | `/api/want-buy/:id/comments` | 发表评论 |
| PUT | `/api/want-buy/comments/:commentId` | 修改评论 |
| DELETE | `/api/want-buy/comments/:commentId` | 删除评论 |
| POST | `/api/want-buy/comments/:commentId/like` | 点赞评论 |
| DELETE | `/api/want-buy/comments/:commentId/like` | 取消点赞 |

### 管理员接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/want-buy/admin/list` | 管理员求购贴列表 |
| DELETE | `/api/want-buy/admin/:id` | 管理员删除求购贴 |
| DELETE | `/api/want-buy/admin/comments/:commentId` | 管理员删除评论 |

## 请求与响应

### 发布求购贴

**请求**
```json
{
  "name": "iPhone 15 Pro Max",
  "description": "想要一个256G的，最好是原色",
  "maxPrice": 8000,
  "categoryId": 1,
  "tags": ["苹果", "手机"],
  "validDays": 7
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 求购的商品名称 |
| description | string | 否 | 详细描述 |
| maxPrice | number | 否 | 期望最高价格 |
| categoryId | number | 否 | 分类ID |
| tags | string[] | 否 | 标签 |
| validDays | number | 否 | 有效期（7/15/30天） |

**响应（201）**
```json
{
  "code": 200,
  "data": {
    "id": "1",
    "userId": "123",
    "name": "iPhone 15 Pro Max",
    "description": "想要一个256G的，最好是原色",
    "maxPrice": 8000,
    "categoryId": 1,
    "tags": ["苹果", "手机"],
    "status": "open",
    "validDays": 7,
    "expireTime": "2024-01-08T00:00:00.000Z",
    "createdAt": "2024-01-01T00:00:00.000Z"
  },
  "message": "发布成功"
}
```

### 求购贴状态操作

| 操作 | 说明 |
|------|------|
| PUT `/:id/found` | 标记为已找到，状态变为 found |
| PUT `/:id/close` | 关闭求购贴，状态变为 closed |
| PUT `/:id/reopen` | 重新开启，状态变回 open |


## 求购贴状态

| 状态 | 说明 |
|------|------|
| open | 开放中，可联系 |
| found | 已找到（买家已购） |
| closed | 已关闭（过期或不想要了） |

## 权限规则

| 操作 | 权限要求 |
|------|----------|
| 查看公开求购贴 | 公开 |
| 发布求购贴 | 登录用户 |
| 修改/删除自己的求购贴 | 发布者本人 |
| 状态操作（found/close/reopen） | 发布者本人 |
| 发表评论/点赞 | 登录用户 |
| 修改/删除自己的评论 | 评论者本人 |
| 管理员删除 | 管理员 |

## 有效期

求购贴默认有效期为7天，到期后自动关闭。可设置为7/15/30天。
